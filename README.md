# Cabo Verde → Dock Sud

Sitio interactivo de una página sobre la inmigración caboverdiana en Argentina, con foco en **Dock Sud** como su núcleo histórico. Desarrollado como introducción para una muestra universitaria.

🔗 **Ver sitio en vivo:** _agregá acá el link de GitHub Pages una vez publicado_
`https://<tu-usuario>.github.io/<nombre-del-repo>/`

## Qué muestra

- Una línea de tiempo interactiva de la travesía, desde fines del siglo XIX hasta hoy
- El plano de Dock Sud, el barrio donde se concentró la comunidad
- Los oficios ligados al agua que definieron a la colectividad
- Fotos del archipiélago de Cabo Verde y de la sede actual de la Unión Caboverdeana

## Tecnología

Un único archivo HTML autocontenido (`index.html`) con CSS y JavaScript embebidos, sin frameworks ni build. Usa Google Fonts (Fraunces + Work Sans) e imágenes propias en `/img`.

## Cómo publicarlo en GitHub Pages

1. Subí este repositorio a GitHub, manteniendo la carpeta `img/` junto a `index.html`.
2. Andá a **Settings → Pages**.
3. En "Source", elegí la rama `main` y la carpeta `/ (root)`.
4. Guardá los cambios: el sitio queda publicado en unos minutos en la URL que te indique GitHub.
